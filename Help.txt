Lua has 8 distinct data types:
type(nil)         -- nil, the absence of a value
type(true)        -- boolean
type(10.4 * 12)   -- number
type("welcome")   -- string
type(print)       -- function
type({})          -- table
type(io.stdin)    -- userdata

Strings can be multi-line with [[ ]].
starting_sequence = [[
Mira, Rumi, and Zoey 
all looked at each 
other in awe, as they
leaped across the stage...
]]
